# VideoPress Lite

VideoPress Lite は、動画ファイルをブラウザ内で圧縮するシンプルなWebツールです。

打合せ録画、現場撮影動画、ドローン動画、プレゼンテーション動画、施工記録動画などを、メール送付やクラウド共有しやすい容量へ圧縮することを目的としています。

## 主な機能

- ドラッグ＆ドロップによる動画投入
- ファイル選択ボタンによる動画投入
- 元動画のファイル名、容量、再生時間、解像度表示
- 解像度、CRF品質、エンコード速度、音声ビットレートの設定
- 圧縮前の概算容量予測
- ffmpeg.wasm によるブラウザ内動画圧縮
- 圧縮結果の容量、削減容量、削減率表示
- 圧縮後動画のダウンロード
- ダークモード
- レスポンシブ対応
- 設定のlocalStorage保存
- 大容量動画の警告表示

## 使い方

1. Webページを開きます。
2. 動画ファイルをドラッグ＆ドロップ、または「ファイルを選択」から読み込みます。
3. 元動画情報と容量予測を確認します。
4. 必要に応じて圧縮設定を変更します。
5. 「圧縮開始」を押します。
6. 完了後、「ダウンロード」から圧縮後のMP4を保存します。

## 対応動画形式

- mp4
- mov
- m4v
- avi

出力形式はMVP段階ではMP4です。

## プライバシー

VideoPress Lite は動画をサーバーへ送信しません。

動画の読み込み、変換、出力生成は ffmpeg.wasm を使ってユーザーのブラウザ内で実行されます。大容量動画ではブラウザのメモリ制限により処理できない場合があります。

## 制限事項

ブラウザ版のVideoPress Liteは軽量動画向けです。

500MBを超える動画や、3000pxを超える高解像度動画では、ブラウザのメモリ制限やffmpeg.wasmの処理限界により失敗する可能性があります。大容量動画を扱う場合は、まず軽量モード、720幅、CRF32、veryfastで再試行してください。

本格運用では、Electron + ネイティブFFmpeg版の利用を推奨します。

## Vercel公開

このプロジェクトは GitHub Pages ではなく、Vercel で公開する想定です。

Vercel設定の想定:

- Framework Preset: Other
- Build Command: 空欄
- Output Directory: 空欄、または `./`
- Install Command: 空欄

`main` ブランチにpushすると、GitHub連携済みのVercelプロジェクトで自動再デプロイされる構成を想定しています。
